# MindInsight 🧠

MindInsight is an AI-powered mental wellness analysis system that helps users understand patterns related to Depression, Anxiety, and Stress.

## Features

- Depression, Anxiety and Stress Prediction
- Artificial Neural Network (ANN) Model
- Personalized Recommendations
- Weekly Trend Analysis
- Digital Mental Health Twin
- Interactive Dashboard
- Flask Backend Integration

## Tech Stack

- Python
- Flask
- TensorFlow
- Keras
- Scikit-learn
- HTML
- CSS
- JavaScript

## How It Works

1. User answers 27 lifestyle and mental wellness questions.
2. Responses are processed and scaled.
3. ANN model predicts Depression, Anxiety, and Stress levels.
4. Results are displayed with visual insights and recommendations.

## Disclaimer

MindInsight is an awareness tool and is not intended to diagnose, treat, or replace professional medical advice. Users with severe results are encouraged to consult a healthcare professional.
